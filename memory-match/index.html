How to play memory match game

Memory matching is a simple concentration game: reveal two cards at a time and remember where each symbol appears. A move is counted when you reveal a pair. Try to match all eight pairs in as few moves as possible. Start by remembering a few locations at a time, then use repeated symbols to build a mental map. The game runs in your browser and does not require an account.
