How to play typing speed test

This free typing speed test gives you a one-minute passage to type. Your words per minute (WPM) estimate is based on correctly typed characters, using five characters as one standard word. Accuracy compares correct characters with the characters you entered. For a fair comparison, use the same keyboard and language each time. Short practice sessions can help you notice progress, but the result is only an estimate and can vary by passage and punctuation.
